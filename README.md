# fleecr

<p align="center">
  <img src="Resources/AppIcon/fleecr-icon-1024.png" width="180" alt="fleecr logo" />
</p>

<p align="center">
  A native macOS client for <a href="https://herdr.dev/">herdr</a>, bringing your AI coding
  agents and live terminals together in one simple interface.
</p>

fleecr helps you view and manage coding-agent sessions across your local machine and remote devices. It is built for a fast, native macOS experience and connects to the real PTY behind each agent.
